社区插件索引随 dsh-web 家族对齐到统一版本 0.4.17，与全家桶 0.4.17 同版本发布。本版本是一次纯增量轮：新增 18 条条目，目录从 106 条增至 124 条，没有条目被退役；同时索引首次改为按 `id` 升序存放，此前「只追加到尾部」的约定被本轮显式取代。包名、条目数据结构、安装方式与线协议均保持不变。

> **兼容性**：本版本没有破坏性变更——`dsh.engines.dsh` 与 `@deepseek-ai/dsh` peer 维持 `>=0.2.2-rc.1` 不变，发布时 `package.json` 除 `version` 外没有任何改动。冻结标识全部保持原样——包名 `@linxin666/dsh-client-ui-community-plugins`；安装方式（同一包名从 registry 安装，`files` 清单与 `exports` 入口不变）；持久化标识（`community.json` 的文件名、条目结构与字段名，profile 里已持久化的 `ui-community-plugins` 挂载行与相关键名）；线协议（bundle patch 里那行惰性 `ui-community-plugins` 行，以及插件对宿主暴露的字段）均未改名或改形。条目结构不增删字段。唯一变化是数组的**排列规则**从尾部追加改为按 `id` 升序插入——这是给贡献者的写入约定，不改变任何读取方看到的数据形状。

### 新功能

- 收录聚合搜索 `dsh-agent-web-search`：把宿主内置的 `web_search` 换成多上游聚合检索，内置 16 个上游，默认只启用 DDGS、Exa、Parallel 三个免 Key 上游，Brave、Tavily 以及 Gemini、Grok 等模型原生检索上游配好凭据后再开启
- 收录终端浮窗 `dsh-ai-terminal-pet`：把 DSH 的会话状态接到 AI Terminal Pet 桌面浮窗，一个常驻置顶小窗显示每个会话是在跑、在等你审批、出错还是已完成，并能与 Claude Code、OpenCode、Antigravity 的会话汇总在同一面板；仅 Windows
- 收录归档会话管理 `dsh-archived-chats`（npm `dsh-archived-chats`）：按工作区管理已归档与未归档会话，支持独立范围正文搜索、只读预览、标签备注、ZIP 备份、来源分支关系图与永久删除确认及重试；条目声明最低 DSH `0.2.2-rc.1`
- 收录产物架 `dsh-artifacts`（npm `@modusensus/dsh-artifacts`）：侧边栏产物架把会话交付过的图片、视频、文件与链接收进一处，按 SHA-256 内容哈希去重，带分类计数、关键词搜索、视频缩略图、灯箱、粘贴与上传（≤25MB）、首次启动回填历史会话日志，并提供 `save_artifact` 工具供模型主动收藏
- 收录助理摄影师 `dsh-assistant-photographer`：先与用户商量景别、机位、穿搭与光影，确认方案后再出图；按角色档案在提示词层保持人物一致，需自备 ComfyUI 服务与至少一个 Checkpoint 模型
- 收录回合费用语音播报 `dsh-cost-voice`：回合结束后用随包本地音频播报人民币估算费用（默认大白饭音色，可切支付宝），优先读取 `dsh-cost-meter` 的每轮费用或按用量与单价估算；不调用 TTS 服务，金额不代替真实账单
- 收录免费多引擎搜索 `dsh-free-search`：37 个引擎可选，默认自动回退链实际覆盖 28 个，支持时间过滤、多源并发、平台搜索、`web_fetch` 与网页设置面板；条目声明宿主下限 `>=0.2.1-rc.2`
- 收录多 Key 轮换池 `dsh-llm-keypool`（npm `@nethiel/dsh-llm-keypool`）：把已配置的供应商/模型组成有顺序的轮换池，当前路由额度用尽或遇到 429 时在同一轮内切到下一条可用路由；侧边栏面板可勾选、排序并显示当前路由、冷却中的供应商与最近切换记录
- 收录黄金质感侧栏 `dsh-logo-golden`：把侧栏的鲸鱼、deepseek 字标与 HARNESS 铭牌重绘为抛光黄金材质，一道斜向金属光带每三秒完整掠过；画布走 `rgba16float` 扩展动态范围
- 收录本地记忆 `dsh-memory-engine`：聊天时自动记下值得记的事，按遗忘曲线变淡、共享关键词自动连线，图谱可旋转、点选与搜索，支持编辑、删除与导出；数据只写本机
- 收录小说摸鱼 `dsh-novel-fish`（npm `@gongfpp/dsh-novel-fish`）：主动展开选中的原生聊天区域时在真实内容下方追加本地 EPUB、TXT、Markdown 小说片段，按书保存进度；条目面向 0.2.x，兼容区间 `>=0.2.1-rc.2 <0.3.0-0`
- 收录 Claude Code 接入 `dsh-oh-my-claude`：把已登录的 Claude Code CLI 作为 DSH 的对话模型提供方，每次请求经 `stream-json` 驱动 `claude -p`，用 CLI 自己的登录，无需 API key 与额外服务
- 收录悬浮重启按钮 `dsh-plugin-restart-button`：在 Web GUI 上加一个可拖动的悬浮重启按钮（仅 Windows 桌面应用），点击确认后关闭并重启应用与 Host，指令发出前可取消；在 CLI 宿主上按钮会显示但重启必然失败
- 收录插件版本升级 `dsh-plugin-upgrader`：在插件页新增「版本」标签，一键与多选升级都走插件管理器自己的安装路径，默认就地替换、不卸载、启用状态不丢；每步显示用时、阶段与原始 pnpm 日志，已发布版本列表（最多最新 80 个）可一键切换
- 收录任务完成彩蛋 `dsh-thanks-carl`：正常完成后按概率显示卡尔图片，失败、取消与中断不庆祝；另可选常驻桌宠与本地喝水、吃饭、休息提醒，默认概率 15%、冷却 30 分钟，不调用模型或系统通知
- 收录工作区色阶 `dsh-workspace-tints`：为侧栏每个工作区从同一条由暖到冷的白瓷色阶取固定色调轻染标题行，并在其会话旁画一条细轨；已完成但未读的会话整行染绿，强度可调
- 收录归档搬运 `slumberpavilion`：把已归档会话的日志与投影记录搬出加载路径，装好约 15 秒后开始自动搬移，提供归档、读取、还原与删除五个工具，其中 `archive_delete` 不可恢复且没有二次确认
- 收录手账一体化 `diy-journal`：手账皮肤与本地样式菜单一体化，按区域选择图片、GIF 或 MP4 并调整布局、胶带、白边与题字；仅适配 DIY 手账本、需皮肤中心，菜单需 Python 3.9+，已在 Windows 验证

The community plugin index publishes on the family's aligned version 0.4.17, on the same version as the dsh-web family's 0.4.17. This is a purely additive round: 18 entries are registered and the catalog grows from 106 to 124 with nothing retired, while the index is stored in ascending `id` order for the first time, replacing the previous tail-only append convention explicitly. The package name, the entry data structure, the install path and the wire protocol are unchanged.

> **Compatibility**: there are no breaking changes. `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer stay at `>=0.2.2-rc.1`, and at release time `package.json` changes nowhere except `version`. Every frozen identifier is unchanged: the package name `@linxin666/dsh-client-ui-community-plugins`; the install path (the same package name from the registry, with the same `files` list and `exports` entry points); the persistence identifiers (`community.json`'s filename, entry shape and field names, plus the already-persisted `ui-community-plugins` mount row and the related profile keys); and the wire protocol (the inert `ui-community-plugins` row of the bundle patch and the fields the plugin exposes to the host) are neither renamed nor reshaped. The entry shape gains and loses no fields. The one change is the array's **ordering rule**, moving from tail append to ascending-id insertion: that is a write convention for contributors and it changes no data shape any reader sees.

### New Features

- Register the aggregation search tool `dsh-agent-web-search`: replace the host's built-in `web_search` with multi-upstream aggregate retrieval over 16 built-in upstreams, of which the three key-free ones (DDGS, Exa, Parallel) are enabled by default while Brave, Tavily and the model-native retrieval upstreams (Gemini, Grok and others) turn on once credentials are configured
- Register the terminal aggregate `dsh-ai-terminal-pet`: connect DSH session state to the AI Terminal Pet desktop float window, one always-on-top window showing whether each session is running, waiting for approval, failed or done, alongside Claude Code, OpenCode and Antigravity sessions in the same panel. Windows only
- Register archived conversation management `dsh-archived-chats` (npm `dsh-archived-chats`): manage archived and unarchived sessions per workspace with scoped body search, read-only preview, tags and notes, ZIP backup, a source-branch relationship graph, and confirmed, retryable permanent deletion; the entry declares DSH `0.2.2-rc.1` as its floor
- Register the artifact shelf `dsh-artifacts` (npm `@modusensus/dsh-artifacts`): a sidebar shelf collecting the images, videos, files and links a session delivered, deduplicated by SHA-256 content hash, with per-category counts, keyword search, video thumbnails, a lightbox, paste and upload (up to 25MB), a first-launch backfill over past session logs, and a `save_artifact` tool for the model to file items itself
- Register the assistant photographer `dsh-assistant-photographer`: discuss framing, camera position, wardrobe and lighting first and only then generate the image, holding the character consistent at the prompt layer from a character profile; it needs its own ComfyUI service and at least one Checkpoint model
- Register turn-cost voice announcements `dsh-cost-voice`: after a turn ends, announce the estimated RMB cost from the audio shipped in the package (the default voice, or Alipay), preferring `dsh-cost-meter`'s per-turn figure or estimating from usage and unit price; no TTS service is called and the amount does not replace a real bill
- Register free multi-engine search `dsh-free-search`: 37 selectable engines with a default fallback chain that effectively covers 28, plus time filtering, concurrent multi-source queries, platform search, `web_fetch` and a web settings panel; the entry declares a host floor of `>=0.2.1-rc.2`
- Register the multi-key rotation pool `dsh-llm-keypool` (npm `@nethiel/dsh-llm-keypool`): arrange configured providers and models into an ordered rotation pool that switches to the next usable route within the same turn when the current route runs out of quota or hits a 429; a sidebar panel selects and orders them and shows the current route, cooling providers and recent switches
- Register the golden sidebar `dsh-logo-golden`: repaint the sidebar whale, the deepseek wordmark and the HARNESS plate as polished gold, with one diagonal metallic band sweeping the whole assembly every three seconds; the canvas runs the `rgba16float` extended dynamic range
- Register local memory `dsh-memory-engine`: automatically note what is worth remembering during a conversation, fade it along a forgetting curve, link items that share keywords, and rotate, pick and search the graph, with edit, delete and export; data is written to this machine only
- Register novel peeking `dsh-novel-fish` (npm `@gongfpp/dsh-novel-fish`): when the selected native chat area is expanded, append local EPUB, TXT or Markdown excerpts below the real content and keep progress per book; the entry targets 0.2.x with the range `>=0.2.1-rc.2 <0.3.0-0`
- Register the Claude Code bridge `dsh-oh-my-claude`: expose a logged-in Claude Code CLI as a DSH conversation model provider, driving `claude -p` over `stream-json` on the CLI's own login, with no API key and no extra service
- Register the floating restart button `dsh-plugin-restart-button`: a draggable floating restart button in the Web GUI (Windows desktop app only) that closes and restarts the app and the Host after confirmation, cancellable before the instruction is sent; on a CLI host the button shows but a restart can only fail
- Register plugin version upgrading `dsh-plugin-upgrader`: a Version tab on the Plugins page whose one-click and multi-select upgrades go through the plugin manager's own install path, replacing in place by default without uninstalling or losing enabled state, with per-step timing, phase and raw pnpm log, and a published-version list of up to 80 releases switchable in one click
- Register the completion celebration `dsh-thanks-carl`: after a normal completion, show the Carl image with a probability, and celebrate nothing on failure, cancellation or interruption; an optional resident desktop pet and local water, meal and rest reminders come along, at a default 15 percent with a 30-minute cooldown, without calling a model or system notifications
- Register workspace tints `dsh-workspace-tints`: give each sidebar workspace a fixed tone from one warm-to-cool porcelain scale, lightly tinting its title row and drawing a thin rail beside its sessions; finished but unread sessions tint green across the row, and the strength is adjustable
- Register archive offloading `slumberpavilion`: move archived sessions' logs and projection records out of the load path, starting about 15 seconds after installation, with five tools for archiving, reading, restoring and deleting, of which `archive_delete` is irreversible and has no second confirmation
- Register the journal suite `diy-journal`: a journal skin and a local style menu in one package, choosing images, GIFs or MP4s per region and adjusting layout, tape, white borders and captions; it fits the DIY journal only, needs the skin center, needs Python 3.9 or later for the menu, and is verified on Windows

### Fixes

- Refresh the store copy of three DDDMUC entries (26dcec1, #58): `dsh-url-router` matches the desktop address bar as it now is, `dsh-free-search` matches the current engine set and takeover rules, and `dsh-delete-session` matches the trash-first behaviour. All three change only `description` and `descriptionEn`; ids, array positions and every other field stay put

### Other Changes

- The index is stored in ascending `id` order (5f83b7c): a new entry goes to its own `id` position instead of the tail, `5c9f645` adds the assertion that pins the order, and the tail-only wording in `CONTRIBUTING.md` and `AGENTS.md` gives way. The previous order was not ascending on `v0.4.16`; this round reads it, sorts by `id` and writes it back
- Every entry added this round took the ordinary registration path: nothing is retired and no rule exception is opened, taking the catalog from 106 to 124 entries, with `pnpm community:check` reporting `community-index: OK (124 entries)`
- Eight `docs(notes)` commits write the 2026-11-08, 11-09, 11-10 and 11-11 registration rounds, the `dsh-free-search` and `dsh-archived-chats` readmissions, and the 2026-11-09 license policy decisions into `.agents/notes/implemented/process/`
- The version aligns from `0.4.16` to `0.4.17` on the same version as the dsh-web family's 0.4.17: this is a single-package repository, so `version` in `package.json` is the only declaration point
- This package builds no client bundle: the `src/` changes touch only the index validator and its tests, and `lib/` is not committed (it is in `.gitignore`) but produced by the release pipeline's `pnpm build`
